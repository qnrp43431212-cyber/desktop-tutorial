# v1.5 게임 기획 확장

## 혈교·천마신교
신규 월드에는 반드시 1개 이상 교단이 존재한다. 세 상태는 혈교+마교, 혈교만, 마교만. 최종 확률 미정. 저장 데이터는 월드가 처음 로드될 때 결정되고 다음 접속 때 유지된다.

마교가 미창설이라면 강호의 점소이 소문 → 흑철령 흔적 → 폐무련장 → 천마계승령 → 내면세계 시련을 거쳐 `M` 창설 메뉴에 버튼이 생기는 사건 `마도귀환`을 구현한다. 혈교는 실종 수사 → 봉인의 지하 제단 → 혈교성유령 → 금제 시련을 거치는 `혈해재림`으로 해금한다. 사건/신물은 모두 이 모드용 창작이며 확인된 특정 원작 명칭이 아니다. 기연 구조물은 일반 도시 건축처럼 흔하게 반복 생성하지 않는다.

이미 존재하는 교단에는 해당 교단과 관계·신분 검증·고유 입교 시험을 통해 가입한다. 교주에 오르는 법은 직접 창설하거나 기존 교주를 죽여 쟁탈하는 것 두 가지. 실제 사망과 처치자 검증은 서버에서 하고, 주변 신도와 장로는 관계·이익에 따라 복종·반발·배신할 수 있다.

## 교단 무공
천마신교: 천마심공, 천마군림보, 천마지, 천마십삼검, 천마육권, 흑살마장, 자전마공, 천리비행, 천마신권, 천마천세장, 천마철질마도, 천마아수라마도, 천마절운도, 흑영투잠. 이 중 여러 명칭은 《이 무림의 미친년은 나야》 팬 정리에서 확인된 것이며 출처 구분 필요. 일반 장르에서 알려진 천마신공·천마신법·천마검법·천마강기도 별도 기록하되 특정 원작의 세부 효능으로 일괄 고정하지 않음.

혈교: 역천혈류대법(작품의 혈교 계통 금제), 혈영신공·흡혈공·혈마수·혈마신공·혈강시술(장르 관습 또는 특정 창작 사례), 혈무도법·적영보(본 모드 창작). **혈교 무공 이름은 전 무협 작품에 공통으로 확정된 공식 목록이 없으므로 임의로 만든 기술을 원작 무공으로 표시하지 않는다.**

## 무기·복장
무공은 각자 `최적무기 → 유사무기 → 불가` 판정이 필요. 비슷한 도검은 사용 가능하되 성능 하락, 전혀 다른 무기라면 발동 금지. 내공심법·패시브는 휠 배치 불가. 복장은 상의·하의·신발 3부위, 내구도 없음, 철 방어구 기준. 정파 각 문파별 다른 디자인, 일반 사파 10종, 무소속 8종, 창설 문파 선택용 3종, 혈교/마교 각 1종. 입문 때 자동지급 계획. 가면·전신후드·면사는 철 투구급, 내구도 있음. 정체 숨김은 목소리·행동·무공·목격자·전투력·관계를 고려하는 별도 인식 시스템 필요.

## 입력과 UI
`M`: 고서풍 `강호록`, 정보/무공/스탯/문파 창설/팀, 현재 경지·보유 금전. `R` 누르는 동안 HUD 12개 동심 배치 슬롯 표시, 조작 중 WASD 이동 가능. R+마우스 휠로 선택 후 놓으면 확정. 실제 무공 배치/사용, 피해량, 내력과 쿨다운은 서버 인증이 필요. 우측 상단에 수련·실전 성장 알림을 간결한 토스트로 출력하되 레벨업 자유 스탯 분배를 도입하지 않는다. 플레이어를 포함한 팀원 사이 공격은 서버 기준 무효.

## 이전에 확정한 설계 유지
31개 항목(정밀형 스탯 29 + 선업·악업 별도), 삼류~생사경 하위 초입·소성·대성·초월, 내면세계 차원 시련, 정파 3시험/사파 유동 시험, 정파 21일 주기/3일 모집, 문파 창설과 무림맹 신고, 객잔·분쟁·기연, NPC 자율 성장/관계/결혼, 고위 무공의 희귀 기연. 미정 수치는 이후 협의.
