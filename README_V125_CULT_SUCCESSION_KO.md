# MURIM LIFE v1.25 — 대마두 계승/비전 사공/직위별 경지 규칙

> **개발 소스 버전이며 실제 NeoForge 전체 빌드 및 인게임 동작은 아직 검증되지 않음.**

## 설정
- 교단은 **마교**와 **혈교**로 구분한다. 세계의 존재 여부는 기존 `CultWorldData`가 관리한다. 어느 쪽도 존재하지 않는 세계는 만들지 않는다.
- **천마**와 **혈마**는 교주 별도 칭호이며, 두 교주의 전용 무공은 이 버전의 대마두 사공 목록에 포함하지 않는다. 교주의 보스 전투·계승식은 후속 단계에서 구현한다.
- **대마두**는 독자적인 사공 수련으로 높은 경지에 오른 교단 간부이다. 초기에는 교단마다 12명으로 총 24명을 배치하는 명부를 갖는다.
- 각 교단에는 250명씩, 전체 **500명의 예비 후계자**가 준비되어 있다. 합계 524명의 **한국어 이름과 사공 524종이 전부 서로 다르며, 64×64 픽셀 스킨 파일 524개도 중복되지 않게 추가**했다.
- 사공의 기본 공격/이동/장법 판정은 기존 공통 무공 엔진을 사용한다. 각각의 고유 연출과 실제 사공 수련 NPC AI는 아직 후속 작업이다.

## 직책과 최소 경지
| 직책 | 최소 경지 인덱스 | 경지명 |
|---|---:|---|
| 외문제자 | 0 | 삼류 |
| 내문제자 | 1 | 이류 |
| 사부 | 3 | 절정 |
| 장로·가주 | 4 | 초절정 |
| 대마두·호법 | 5 | 화경 |
| 대호법·좌호법·우호법 | 6 | 현경 |
| 교주·천마·혈마 | 7 | 생사경 |

교단 초기 대마두는 현경·생사경으로 시작하며, 각 교단의 12개 직위의 최소 경지도 저장 데이터와 독립 규칙으로 검증한다. 기존 문파 창설자는 세이브 호환을 위해 소급 강등하지 않는다.

## 사망 후 승계 (새 명부는 기존 NPC·월드 데이터와 분리된 SavedData)
1. 서버가 기록한 **해당 실체 NPC의 사망만** 승계 발동 조건이다. 같은 이름·태그를 지닌 다른 개체로 위조할 수 없다.
2. 죽은 대마두의 이름/사공/스킨은 사망자로 남고 다시 할당하지 않는다.
3. 현재 자리보다 아래에 있는 **필요 경지를 만족하는 직위자**가 승격하고, 남은 공석을 같은 방식으로 메운다.
4. 최하위 자리가 비면 예비 명부의 새로운 인물을 **한 명만** 배정한다. 예비 명부가 소진되면 자리가 비지만 교단 자체는 사라지지 않는다.
5. 상위 승계가 가능한 NPC가 없으면 높은 자리에는 공석을 남겨 자격 없는 인물이 자동 승진하지 않는다.
6. 기존 청크·NPC UUID를 재사용하지 않으며, 이미 등록된 실체 NPC는 중복 생성하지 않는다.
7. 승격한 NPC가 로드되어 있다면 이름표·직위·경지·전투 능력치를 갱신하고, 언로드 상태라면 재로딩할 때 반영한다.

## 플레이어 기술 제한과 경지 돌파
- 문파를 창설하거나 마교·혈교의 수장이 되었다는 이유만으로 대마두 사공을 습득할 수 없다.
- 사공을 배우려면 해당 대마두를 직접 쓰러뜨려 **그 사공의 비결 단서**를 획득하고, 그 인물의 경지 이상과 기술 수련 횟수 조건을 만족해야 한다.
- `/murim learn <사공명>`은 조건을 충족한 경우에만 성공한다. 고위 인물의 처치나 이름표만으로 모든 무공이 열리지는 않는다.
- 플레이어 경지 돌파는 `/murim breakthrough`로 시도한다. 전투력·수련·내력·피로도·일일 제한을 서버에서 확인한다.
- 새 문파 창설에는 초절정 이상, 설립 문파를 마교/혈교로 전환하려면 현경 이상을 요구한다. 기존 창설자는 자동 강등하지 않는다.
- 교주의 **천마·혈마 전용 무공**, 후계/교주 즉위식, 완성형 무공 비급 퀘스트는 아직 포함하지 않는다.

## 관리자 시험 명령
- `/murim cult status`: 현재 월드의 마교·혈교 존속 여부, 살아 있는 대마두 수, 남은 예비 명부.
- `/murim cult spawn 마교` 또는 `/murim cult spawn 혈교`: 관리자 권한으로 오버월드 안전 지점에 등록된 대마두 1명을 시험 생성. 한 번에 전체 24명을 소환하지 않는다.
- 테스트 생성은 기본 거점 자동 생성과 별개다. **교단의 별도 본산·자연 생성 배치는 아직 후속 작업**이며, 이 명령만으로 자동 본산 생성이 이루어지지는 않는다.
