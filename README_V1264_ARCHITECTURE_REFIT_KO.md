# MURIM LIFE v1.26.4 — 문파·객잔 건축 구조 및 실내 개선

## 사용자 스크린샷에서 확인한 문제

- 내부 침실에 칸막이 없이 침대만 놓여 있거나, 넓은 홀의 가구가 빈약한 문제
- 문파 외벽의 진한 색띠가 벽과 구분되지 않고 억지로 붙은 느낌을 주는 문제
- 울타리 블록의 연결 속성이 저장되지 않아 난간이 끊겨 보이는 문제
- 기둥·지붕·외벽·실내의 건축적 일체감이 낮은 문제

## 전통 건축 참고 방향

- 목구조 기둥 → 도리·보 → 처마/지붕 연결을 읽을 수 있게 하고, 흰색 회벽은 목재 골조와 구분한다.
- 안마당/복도에서 공적 공간 → 객실/침실 순으로 동선을 배치한다.
- 객실에는 낮은 탁자, 책장, 보관함, 침구, 식물 등 용도에 맞는 최소 가구를 둔다.
- 객잔·사찰·문파 숙소·서고·명상실은 서로 다른 가구 유형을 사용한다.

참고 문헌/사진: MDPI *Buildings* (2023) 「Heritage and Rehabilitation Strategies for Confucian Courtyard Architecture」, doi:10.3390/buildings13030599; Chen et al. (2020) 「Research on traditional vernacular dwellings in the Li Canal reach of the Grand Canal」, doi:10.1080/13467581.2020.1756822; Beijing courtyard and Suzhou Jiangnan courtyard photo references.

## 실제 데이터 변경

- `ARCHITECTURE_V1264_MANIFEST.json`에 원본·수정본 SHA-256을 기록한 **336개 NBT 파일**을 변경했다. 대부분의 비해당 구조물은 보존했다.
- 기존 반복적인 강렬한 테라코타 가로띠 중 외벽 전체를 감싸는 구간을 주변 목재와 일관된 보로 바꾸었다. 단, 고유 문파 색을 표현하는 모든 장식을 무조건 없애지는 않았다.
- 기존 울타리 블록의 N/E/S/W 연결 속성을 실제 이웃 블록과 일치시키도록 교정했다.
- 공통 문파 숙소 1층 후면에 **2개의 독립된 침실과 정상적인 2블록 높이 출입문**을 추가했다.
- 대형 객잔 1층 후면 객실을 분리하고, 기존 침대를 유지하면서 수납함·책장·화분 등의 가구를 추가했다.
- 다른 침실에도 침상 옆 수납함·책장·화분을 배치했다. 서고·명상실·객잔·약방·정청에는 용도에 따른 기본 가구를 보완했다.
- **새 구조물 건축 위치나 기존 마인크래프트 월드 저장 파일은 수정하지 않았다.** 이미 월드에 설치된 건축물은 자동 갱신되지 않는다.

## 검사 및 한계

- NBT 총 635개 검사: 좌표 중복 0, 범위 초과 0, 짝이 맞지 않는 문 0.
- 본 변경은 **구조물 데이터의 1차 개선**이다. 635개를 모두 새로 설계한 것은 아니다. 특히 복잡한 외벽 장식, 2층 동선, 현판·기와의 디테일과 각 건물의 독창적인 미관은 실제 게임에서 추가 점검해야 한다.
- Java 게임 코드, 네트워크, NPC 등은 이번에 수정하지 않았다.
- 기존 **Gradle 빌드 성공**은 이전 v1.26.3에 해당한다. 새 데이터는 정적 검사와 NBT 문법 검사를 했지만 Minecraft 월드 내 **실제 배치·충돌·시각적 품질**을 검증했다고 주장하지 않는다.
- 스크린샷 제공된 정확한 건물이 무엇인지 식별되지 않은 경우 전부 일대일로 대응했다고 주장하지 않는다.

## 배포

- `MurimLife_v1_26_4_Architecture_Refit_Source_1.21.1.zip`은 수정된 모든 원본 NBT를 포함하는 개발 소스다. GitHub에 이 소스를 덮어써서 Actions로 재빌드할 수 있다.
- `murimlife-0.1.26.3-architecture-resource-hotfix.jar`는 직전 GitHub Actions에서 **이미 빌드된 v1.26.3 JAR의 클래스 코드는 그대로 두고**, 336개의 구조물 NBT만 교체한 즉시 시험용 패키지다. 모드 목록에 표시되는 내부 버전은 v1.26.3이다. 기존 JAR과 동시에 설치하면 안 된다.
- **새 테스트 월드를 사용**하거나 아직 배치되지 않은 신규 구조물에서 확인한다. 저장 월드는 백업 후 실험한다.
