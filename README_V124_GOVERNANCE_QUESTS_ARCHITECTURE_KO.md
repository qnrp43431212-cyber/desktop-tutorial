# MURIM LIFE v1.24 — 문파 재정·임무·평판·건축 감사 (개발 소스)

**지원:** Minecraft Java 1.21.1 / NeoForge 21.1.235 / Java 21 / Epic Fight 21.17.3.1 연동 소스

> **검증 상태:** Java 구문/중복 검사와 순수 Java 규칙·리소스·NBT 정적 검사만 완료. NeoForge Gradle 전체 컴파일, JAR 구동, 멀티플레이 인게임 테스트 **미완료**. ZIP은 배포용 완성 JAR이 아닙니다.

## 1. 문파 소속 NPC와 플레이어 제자: 3일 급여 / 7일 체불

- 플레이어가 창설한 문파의 문파원(플레이어와 모집한 NPC)은 마인크래프트 **3일마다 문파 금고**에서 직급에 따른 용돈을 받습니다. 처음 체불이 시작된 뒤 **7일 경과**하면 남은 채권을 보관하고 문파를 탈퇴합니다. 3일마다 미지급이 발생할 때마다 충성도가 감소합니다.
- 직급과 지급액(문): **외문제자 75, 내문제자 180, 사부 420, 장로 850**. 계승한 종래 화폐 은 값은 보존하고 **100문=1은량, 10은량=1금량**으로 환산합니다.
- 사파 탈퇴자는 체불금의 **80%**를 문파 금고와 가주 소지금에서 강제 회수합니다. 가진 돈보다 많은 액수를 생성하지 않으며 미수금은 남습니다. 사파 가주 평판 -12.
- 정파 체불은 무림맹 감찰 사유가 됩니다. **마교·혈교는 급여 의무에서 면제**되며 체불·감찰 시스템 적용 대상에서 제외됩니다.
- NPC 영입/승급/해임은 NPC와 6블록 이내에서 `~` 대화 메뉴에서 수행합니다. 영입 시 성공 판정이 있으며 기존 지도자·기연 수호자·대회 관중은 영입할 수 없습니다. NPC 계약은 UUID와 별도의 SavedData로 저장되므로 청크 언로드 후에도 체불·소속이 유지됩니다. 체불 중 해임은 차단됩니다. 일반 NPC의 완전한 문파 충성 행동 AI와 독자 생활 스케줄은 향후 구현 대상입니다.
- 문파 성향 전환은 가주만 가능하며 소속 구성원·미결 채무·감찰이 있을 때 전환하여 체불 책임을 회피하지 못하게 했습니다.

## 2. 무림맹 감찰 및 가주 시정 명령

정파 문파원이 7일간 급여를 지급받지 못해 탈퇴하면 무림맹이 가주에게 **15일 시정 임무**를 내립니다.

**임무 이름: 백성 구휼과 강호 치안 회복**

1. 실제 기연 수호 적 **3명** 처치 (서버 전투 처치 기록)
2. 철괴 **12개** 보급 (인벤토리 실제 소모)
3. 빵 **8개** 보급 (인벤토리 실제 소모)
4. 가주 개인 **수련 8회** (임무 발급 이후 기록)

네 가지를 기한 내 충족하면 무림맹이 저장된 플레이어·NPC 문파원 채무를 대납하고 **선업 +35, 평판 +35** 보상합니다. **실패하면 정파 자격 박탈, 평판 -100, 남아 있는 문파원의 70% 탈퇴**가 발생합니다. 기존 체불 채권은 보존됩니다. 자동 복귀는 없습니다.

명령: `/murim sect audit`, `/murim sect supply iron`, `/murim sect supply bread`, `/murim sect finances`, `/murim sect alignment 정파|사파|마교|혈교`.

## 3. 등급별 임무: 총 304개

| 접수처 | 견습 | 하급 | 중급 | 상급 | 최상급 | 합계 |
|---|---:|---:|---:|---:|---:|---:|
| 무림맹 | 30 | 30 | 30 | 30 | 30 | 150 |
| 사도련 | 27 | 27 | 27 | 27 | 27 | 135 |
| 주민 | 10 | 9 | 0 | 0 | 0 | 19 |
| **총계** | | | | | | **304** |

- 각 접수처에서 자신의 등급별 **5개 임무**를 보여주며 **3마인크래프트 일마다 목록이 갱신**됩니다. 수락 후 **3일** 내 완수하지 못하거나 포기하면 평판이 깎입니다.
- 서버가 입증할 수 있는 다섯 목표 유형: **수련·실제 적대 전투 승리·아이템 납품·기연 수호 적 처치·기연 구조물 방문**. 고유 명칭과 단계별 요구량/보상을 304개 데이터로 정의했으며 일부 기초 목표는 등급별 테마가 공통입니다.
- 정파는 무림맹, 사파는 사도련에서 접수합니다. 무소속 용병도 양측 접수 가능하지만 **최대 하급**으로 접수 범위가 제한됩니다. 무소속은 시민 의뢰도 접수 가능합니다.
- `~` 대화에서 임무를 연 뒤 등급/목록을 선택합니다. 본부 NPC가 활성화되지 않았다면 **실제 완공된 본부 근방**에서 `/murim quest board alliance` 또는 `/murim quest board sado` 명령으로 접수합니다. 생성되지 않은 건물 위치를 만들지는 않습니다.
- 명령: `/murim quest status`, `/murim quest rank 0..4`, `/murim quest accept 1..5`, `/murim quest deliver`, `/murim quest abandon`.
- 전체 임무·요구량·금전 및 평판/선업 보상은 `docs/MURIM_LIFE_v1_24_전체임무_304종.csv`와 `src/main/resources/data/murimlife/quests/catalog.json` 참조.

## 4. 평판과 신분 은폐

- 평판은 **0~1000** 범위로 선업/악업과 독립된 수치입니다. 평판이 높아지면 가까운 NPC가 알아보는 확률이 증가합니다.
- 마스크 `murimlife:mask`, 두건 `murimlife:full_hood`, 면사 `murimlife:veil` 착용 중에는 거리 인식/대화 인지 시스템에서 신분을 숨깁니다. 평판 자체를 삭제하지는 않습니다.
- 긍정적 혜택: 상점 구매가 최대 15% 할인, 매각 프리미엄 최대 10%, 정보료 할인, 임무금 추가 상향 최대 21%, 일정 평판의 임무 등급 해금 도움.
- **평판 증가만으로 선업/악업이 변하지 않습니다.** 구휼 임무 등 별도 선행 목표의 선업 보상만 별도 합산합니다.
- `/murim reputation`으로 평판과 얼굴 은폐를 확인합니다.

## 5. 12종 기연 + 기존 건축물 감사

- 기존 기연 12종(동굴형 6, 지상 폐허형 6)의 직각 사각형 절차적 바닥/폐벽을 **불규칙한 윤곽, 붕괴된 기둥, 돌·이끼·잔해, 비대칭 통로** 형태로 조정했습니다. 기연 함정과 수호 적은 기존 v1.23 연결을 유지합니다.
- 기존 NBT 건축물 **635개 파일, SHA-256 기준 내용이 서로 다른 구조물 341개**를 전수 검사했습니다. 파일 로드 불가, 좌표 범위 벗어남, 같은 좌표 중복, 짝이 틀린 양쪽 문이 없음을 확인했습니다.
- 계단 **4,733개** 중 아래가 비어 있는 **742개**는 10종 탑 지붕 처마(각 73개) 및 무림대회 경기장의 디자인 요소(12개)에 한정됩니다. 처마를 일반 벽돌로 받치는 것은 미관/지붕 구조를 망가뜨릴 수 있어 변경하지 않았습니다.
- 기존 NBT 파일은 위험한 자동 치환을 하지 않고 **원본 보존**했습니다. 의자·안벽·계단의 실제 시각적 자연스러움과 완성된 무협 건축 외관은 게임에서 정면/측면/내부를 확인할 때만 최종 판정할 수 있습니다. 현재는 3D 인게임 스크린샷 검증이 불가합니다.
- 전체 세부 수량/재료/구조물별 검증 기록: `qa_v124_structures_detailed.json`.

## 7. 알려진 제한

- 임무 GUI는 그래픽 별도 화면이 아닌 **클릭 가능한 대화형 채팅 메뉴**입니다.
- 임무 목표 분류는 5가지이고 등급별 수치 차등 및 고유 이름을 사용합니다. 304개의 고유 연출/애니메이션을 전부 제공하지는 않습니다.
- 무림맹/사도련 전용 NPC는 **실제 생성되고 진영 정보가 기록된 NPC**를 통해 접수됩니다. 구조물 생성이 꺼진 세계에서는 `/murim quest board ...`도 본부 좌표가 없으므로 접수할 수 없습니다.
- NPC 계약은 금전·직급·소속에 관한 저장 시스템입니다. 완전한 문파 정치 AI·자율 임무 수행·가구를 사용하는 행동까지 구현했다는 의미는 아닙니다.
- 세계/서버 재시작 후 SavedData 유지 여부, UI·네트워크 패킷 호환성, 블록 겹침, 패턴 미관, 서버 TPS는 **인게임 미검증**입니다.

## 8. 실제 게임 빌드 후 확인해야 할 수동 검증 순서

1. 새 테스트 월드에서 문파 창설 및 정파/사파 성향 설정 후 금고에 임의의 금액을 예치하고, NPC 영입·직급 승급·3일 급여 지급을 각각 확인합니다.
2. 별도 테스트 월드에서 문파 금고를 비우고 **7일 체불**: NPC와 플레이어 문파원의 채권/충성도/탈퇴 상태가 게임 저장·재접속 후 유지되는지 확인합니다.
3. 정파 감찰 시정 임무: 3마리 기연 수호 적 처치, 철괴 12개·빵 8개 납품, 수련 8회 후 채권 대납·선업과 평판 분리 확인; 다른 월드에서는 15일 만료와 정파 자격 박탈/70% 탈퇴 확인.
4. 사파 체불 시 금고와 가주 개인 지갑 합계보다 많이 회수하지 않는지, **가용 금액 범위에서 80% 한도**로 회수하고 부족분 채권을 유지하는지 확인합니다. 마교·혈교의 지급 면제 확인.
5. 무림맹·사도련 거점/주민에게 `~`로 접근하여 5개 임무 보이기, 3일 후 목록 교체, 수락/납품/성공/기한 초과/평판 감소, 무소속 용병 등급 제한 확인.
6. 가면/두건/면사 착용 전후 NPC 신분 인지와 상점 할인 확인. **평판 상승만으로 선업이 오르면 버그**입니다.
7. 무림맹·사도련·문파 3~5종과 기연 12종을 각각 건물 밖·중앙·옥상·내부에서 관찰해 지붕 처마, 벽을 통한 이동, 문 여닫힘, 앉는 의자, 계단 동선, 함정 피해, 수호자 스폰을 실제 확인합니다.
8. 멀티플레이에서 두 사람이 같은 임무를 수락/완료하거나 NPC를 동시에 영입할 때 중복 보상·UUID 복제·재접속 손실이 없는지 확인합니다.

> 주의: 위 항목은 **검증 절차**일 뿐, 이번 환경에서 이미 실행하여 통과했다는 뜻이 아닙니다.
