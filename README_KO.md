# MURIM LIFE v1.6 — Minecraft 1.21.1 NeoForge 무협 모드 소스 / 리소스

> ⚠️ **초기 플레이 가능 코드를 포함한 미완성 개발 프로젝트입니다.** `.jar` 완제품이 아닙니다. 이 환경에서는 Gradle 및 NeoForge 의존성을 다운로드할 수 없어 전체 컴파일과 실제 Minecraft 실행 검증을 수행하지 못했습니다. 배포 전에 반드시 빌드 오류 수정 및 게임 테스트가 필요합니다.

사용자의 v1.0~v1.5 기획과 문파·무공·기연·혈교/마교·복장 자료를 보존하고 v1.6을 추가한 개발용 원본입니다. 코드를 열어 수정할 수 있으며 독립 게임규칙과 리소스 검증은 완료했습니다.

## 파일 구성

- `src/main/java/kr/murimlife/`: NeoForge 모드 코드. M 메뉴, R 무공휠, G 패링, 서버 저장, 수련, 기초 전투, 문파모집/대회 표시, 일부 무공 시전, 명상석 상호작용
- `src/main/resources/`: 38종 문파 도복(114개 아이템), 7등급×16종 무기(112개 **신규**, 기존 기본 16개와 별도), 96종 인간형 NPC 스킨, 7개 수동 배치용 NBT 구조물, 한국어·영어 명칭
- `models_source/`: 블록벤치 기반 인간형 모델, 명상 제단 모델, `murim_npc.geo.json`과 5개 기본 애니메이션 곡선. **NPC 엔티티·GeckoLib과 아직 연결되지 않음**
- `design_data/v16_epithet_catalog.json`: 275개 일반/창작 별호, 조건, 중복 불가 규칙. 현재 서버 규칙이 추적하는 조건에서 획득 가능; 그 외 별호 조건은 이벤트 연결 필요
- `design_data/v16_martial_catalog_balancing.json`: 261개 조사 무공명과 출처 상태, 등급 및 임시 위력·내력·쿨타임·시각효과 템플릿. **261개 고유 기술 시전/모션이 구현되었다는 뜻이 아님.** 실제 전투에 연결한 원형 기술은 `MurimCombat.java`의 12개(그중 패시브 1개)
- `design_data/v16_npc_templates.json`: 96명 구별되는 NPC 프로필/텍스처 목록. 서버에서 96명 가상 무림인의 장기 성장을 계산하지만 월드에 실제 인간형 NPC를 소환하는 엔티티/렌더러는 아직 없음
- `design_data/v16_world_calendar.json`: 문파 모집 및 대회 기획값
- `rules_engine/`: Java 21 단독 컴파일 가능한 별호·경지·모집·무기·무림대회 계산 엔진과 테스트
- `docs/`: 개발 상세 보고서 및 기존 팔레트

## 실제 게임 코드에서 시험할 조작

| 키/명령 | 상태 |
|---|---|
| `M` | 강호록의 기본 정보/무공/스탯/문파/팀 탭. 서버 프로필 동기화, 습득한 기술을 선택칸에 배치 |
| `R` 길게 + 마우스 휠 | 이동을 유지하면서 12칸 표시, 키를 떼면 서버에 선택/시전 요청 |
| `G` | 약 9게임틱의 패링 시도. 현재 플레이어 대 플레이어 공격에서만 실제 취소 처리 |
| `/murim status` | 경지/종합 전투력/은화/대표 별호 |
| `/murim train 근력` | 10초 단위 예시 수련; 능력치가 점점 느리게 성장, 월드 저장 |
| `/murim train 기교` | 기교 수련. 다른 기본 스탯명도 사용 가능 |
| `/murim learn 연환검` | 수련량 조건을 충족한 뒤 기술 배움; M 화면에서 12칸에 배치 |
| `/murim aliases` | 보유 별호 목록 |
| `/murim display 협객` | 보유 별호 중 대표 별호 선택 |
| `/murim recruitment` | 문파별 모집 가능 기간 확인 (21일 주기, 문파별 시작 시점 다름, 소림 0일째 시작) |
| `/murim tournament` | 대회 일정 및 신진무인 자격 확인 |
| `/murim tournament enter` | 임시 **문자 기반** 대련 3회 및 우승 보상. 실제 대회장 전투는 미구현 |
| `/murim npcs` | 서버에 저장된 가상 NPC 시뮬레이션 수 확인 |
| 명상석 블록 우클릭 | 기감 수련의 게임 내 입구. 실제 내면세계 차원은 미구현 |

일부 기본 무공은 캐릭터가 미리 배운 상태(`기본검격`)이고, 나머지는 수련량이 필요합니다. 패시브(`호흡조절`)는 기술휠에 배치할 수 없습니다.

## 기초 밸런스 기본값 (변경 가능)

- 경지: `삼류→이류→일류→절정→초절정→화경→현경→생사경`, 매 경지의 `초입→소성→대성` 및 `초월` 표시
- 전투력 계산: 9가지 기본 능력치+수련·내공+피로·부상 상태를 종합하는 기본식. 29항목 전체 정밀 시뮬레이션 공식은 아직 미구현
- 무기: 범철/정철/강철/백련강/현철/명장/신병, 공격력 및 내구도 단계화
- 모집: 21일에 약 3일 개방, 소림은 월드 생성 당일 개방; 나머지 문파는 월드 시드별 각기 다른 오프셋
- 정기 대회: 42일에 첫 개막, 84일 주기, 3일간 참가 가능, 계층별 우승 상금 800/2,200/5,000은
- 신진 대회: 무림인 생활 시작일로부터 30~43일 사이, 일류 이하, 우승 250은. 임시 문자 대련
- 별호: 같은 월드 전체에서 특정 별호 1명만 보유, 캐릭터당 여러 개 보유 가능. NPC 가상 시뮬레이션도 동일한 별호 저장 사용

## Minecraft에서 구조물만 먼저 시험하기

`MurimLife_v1_6_Structures_Datapack.zip`을 해당 월드의 `datapacks` 폴더에 넣고 `/reload` 한 뒤 OP 권한으로 다음과 같이 호출할 수 있습니다.

```mcfunction
/place template murimlife:jianghu_inn
/place template murimlife:martial_tournament_arena
/place template murimlife:murim_alliance_headquarters
/place template murimlife:meditation_hall
/place template murimlife:heavenly_demon_palace
/place template murimlife:blood_cult_sanctum
/place template murimlife:mountain_sect_pavilion
```

구조물은 **수동 설치 가능한 템플릿**이며 자연 월드 생성·NPC 인구 배치와 아직 연결되지 않았습니다. 커맨드는 Minecraft 1.21.1의 `/place template` 문법을 기준으로 제안한 것이며 게임 내 미검증입니다.

## Windows 환경 빌드 준비

1. Java 21 설치.
2. [공식 NeoForge 1.21.1 MDK](https://github.com/NeoForgeMDKs/MDK-1.21.1-NeoGradle)에서 `gradlew`, `gradlew.bat`, `gradle/wrapper/` 파일을 확보하여 이 프로젝트 루트로 복사.
3. Gradle과 의존성을 받을 수 있는 PC에서 프로젝트 루트 터미널을 열고 `gradlew.bat build` 실행.
4. 빌드 오류가 발생하면 해당 에러를 수정한 뒤 `build/libs/` 산출물을 NeoForge 1.21.1 개발 실행 환경에서 시험.
5. 기존 월드가 아닌 **새 테스트 월드와 백업**에서 먼저 시험하세요. 미완성 모드가 충돌을 일으킬 수 있습니다.

`bash scripts/test_rules_v16.sh` 또는 `python scripts/verify_v16_assets.py` 는 Minecraft가 없어도 실행 가능합니다.
