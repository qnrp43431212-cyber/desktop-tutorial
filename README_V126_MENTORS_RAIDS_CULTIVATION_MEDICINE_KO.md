# MURIM LIFE v1.26 — 대마두 사제 관계 · 침공 사건 · 주화입마 · 영약

**종류:** Minecraft 1.21.1, NeoForge 21.1.235, Epic Fight 기반 통합 MDK 소스. **JAR 아님.**

## 1. 교단 인명 500개에 대한 정정

- **24명**은 대마두의 초기 12직위×2개 교단에 *할당*된 인물이다. 이들 모두가 월드에 자동으로 소환되는 것은 아니다.
- **500개는 현재 활동하는 계승자 NPC가 아니다.** 향후 무림인 및 교단 NPC를 계속 생성할 때 중복 방지용으로 확보한 미래 고유 인명 자원(마교 250개, 혈교 250개)이다.
- 원본 v1.25의 524개 개인 프로필은 기존 월드/사공 호환성을 위해 유지했으며, 미래 이름만 추출한 별도 자료는 `design_data/v126_future_cult_npc_names_500.json`에 있다.
- 현재 `CultRoster`는 자리가 비면 이 중 하나를 *그때* 하위직으로 실체화할 수 있다. 일반 신규 NPC를 생성할 때 이 예비 인명 은행을 공용으로 소비하도록 연결하는 전역 이름 할당기는 아직 미구현이다.

## 2. 마교·혈교 입교와 대마두 사제 관계

- `~` 키로 대마두에게 접근한다. 대화 메뉴 **19. 입교 요청**, **20. 제자 요청**, **21. 사부 수련 요청**이 나타난다.
- 이미 다른 문파에 소속되어 있으면 먼저 정상 탈퇴해야 한다. 마교/혈교 가입 시 교도 직책만 얻으며 교주나 대마두 사공을 자동으로 얻지 않는다.
- 교도 확보가 중요하기 때문에 대체로 입교를 수락하도록 했다(기본 90~97%). 사제 요청도 비교적 수락하나 경지가 낮을수록 까다롭다(58~92%).
- 적대적인 거절은 거절 판정 중 **1~3%**의 낮은 빈도이며, 대체로 대화만 거절한다. 평소의 대마두는 신규 교도 모집을 위해 선제 공격을 하지 않는다. 부당 공격을 받으면 반격한다.
- 사제 전수는 1일 1회, 사전 수련 3회 조건이다. 사부 경지에 따라 5~17차례 이상의 수업이 필요하며, 간혹 스승이 구결을 숨겨 진기 불안정이 상승한다. 사공 습득에는 경지·수련 요구량을 모두 만족해야 한다.
- 명령 `/murim mentor`(현황), `/murim mentor leave`(사문 떠나기), `/murim learn <사공>`(전수 완료 이후).

## 3. 침공·점령 시도 사건

- 마교/혈교가 실제 인간형 무장 NPC 3~5명(정파 감찰 사건은 4명)으로 이루어진 침공대를 생성한다.
- 거점 가까이에서 사건이 시작되면 문파 본부 습격/점령 시도로, 그 밖에서는 길목 기습으로 표시한다. **정식 영토 소유권을 변경하는 완전 점령 시스템은 아직 없음.**
- 자연 습격은 사교 소속이 아닌 경지 일류 이상 플레이어 주위에 드물게 나타나고, 개인별 5일 이상의 간격과 서버 전체 사건 수 제한을 둔다.
- 정파 가주에게 체불에 따른 무림맹 감찰이 진행 중이면 2일 이상의 간격으로 격퇴 기회를 만든다. **직접 습격군 3명 이상 처치하고 한 번의 습격을 끝까지 막으면 감찰 임무 성공.** 기연 수호자 처치·철괴·빵 납품은 더 이상 감찰 요건이 아니다.
- 피해 및 처치 기록은 서버가 판정하며 `CultRaidService`의 SavedData에 활동 중인 사건과 주기를 보존한다. 주위에 적절한 생성 공간이 없으면 습격이 시작되지 않을 수 있다.

## 4. 주화입마·심마 해소 사건

- 돌파 자체로 무조건 주화입마가 오지 않는다. 영단 과다복용, 높은 피로, 낮은 정신력, 무리한 운기조식 등이 위험도를 올린다.
- 주화입마 강도 1~4단계, 단계별 3~6개의 심마 대응 순서가 존재한다.
- `/murim qi`, `/murim qi confront` 후 채팅창 3개 선택지에서 기의 증상에 맞는 대응을 제한시간(각 약 14초) 안에 선택한다.
- 실패하면 강도가 심해지고 피로·경지 진척·후유증이 나빠진다. 성공하면 더 높은 강도일수록 깨달음·무공 숙련 보상이 커지며, 후유증으로 일정 기간 느린 내력 회복/감속이 있다.
- 돌파 시 심마가 발생하면 해당 경지는 성공적으로 심마를 벗어나야 완료된다.
- 청심단·안혼단·정기단은 완전 치료가 아니라 진정·부담 경감으로 작동한다.
- 현재 심마 이벤트는 선택지 기반의 초기 구현이다. 별도의 내면세계 차원과 애니메이션 전투는 미완성이다.

## 5. 영약 24종 및 약탕기

- 영약·영단 **24종**: 8종 약초, 15종 조제 단약 및 정체불명 영단 1종. 각 내력 회복량, 피로 영향, 체내 불안정량, 깨달음, 가격 등이 다르다.
- 문파별 전승 약재 이름(예: 소림 대환단, 무당 구전영단, 마교 마심단, 혈교 용혈단)은 레시피의 기원·표시를 구분하지만 **문파별 전용 제작 제한·부속 약방의 자동 생성은 아직 없음**.
- `herbal_brewing_pot` 블록 제작: 돌 벽돌 5개(상단 양끝+하단 3개는 실제 패턴 참고), 구리 주괴 2개, 가마솥 1개. 설치한 약탕기 우클릭 또는 5블록 이내 `/murim alchemy`로 제조식 표시. `/murim alchemy brew <영약ID>` 제조.
- 원료 2종 + 유리병 1개 실제 소모. 고급 영약 제조에는 누적 수련 30~75회가 필요하다. 현재 별도 약방 GUI 대신 채팅 클릭 메뉴 사용.
- 약재 상인에게 `~` 키 대화 → 상점에서 기초 영약 판매, 정체불명 영단은 재고 갱신 4회 중 약 1회 등장하는 구성을 적용했다. 섭취 시 실제 성분이 드러난다.

## 테스트 및 알려진 제한

- 독립 Java 규칙 테스트: **2,803개 항목 통과**. 기존 v1.21~v1.25 독립 테스트 통과.
- Java **83개 파일 구문/중복 선언 검사** 통과. NeoForge API 타입 검사와 마인크래프트 인게임 검사는 아님.
- 콘텐츠/JSON/PNG/구조물 기초 무결성 검사와 기존 NBT 리소스는 보존.
- Gradle Wrapper가 `services.gradle.org` DNS 조회 실패로 다운로드되지 않아 **Gradle 전체 빌드와 실제 구동을 검증하지 못함**.
- 특히 의약품 우클릭 소비, 서버 이벤트 API, 전투 AI, 네트워크 동기화, 적 생성 및 문파 임무 시뮬레이션은 실제 서버 테스트가 필요하다.

### 실행 준비

1. Java 21 설치 및 이 소스 압축 해제.
2. `QA_V126_WINDOWS.cmd` 실행으로 Java 구문/독립 규칙 검사.
3. 인터넷 연결된 환경에서 `BUILD_WINDOWS.cmd` 또는 `gradlew.bat clean build --stacktrace`로 컴파일.
4. 오류 발생 시 `build_log`와 최신 `latest.log`를 보내면 재수정 가능.
