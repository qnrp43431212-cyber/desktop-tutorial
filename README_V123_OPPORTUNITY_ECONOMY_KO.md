# MURIM LIFE v1.23 — 기연·경제·정보 거래·NPC 상호작용

대상: Minecraft Java 1.21.1 / NeoForge 21.1.235 / Java 21 / Epic Fight 21.17.3.1

## 중요: 검증 범위

이 버전은 **개발 소스 ZIP**입니다. 스스로 실행되는 모드 JAR가 아닙니다. Java 소스 문법 검사·중복 검사, 독립 순수 Java 테스트, 데이터 무결성 및 연결 구조 정적 검사까지 수행하였으나, 네트워크 접근 제한으로 Gradle Wrapper의 NeoForge 전체 의존성 다운로드 및 컴파일/실제 Minecraft 실행은 하지 못했습니다. 게임 내 GUI·자연 생성 확률·NPC 스폰/저장 등은 아직 확정된 결과가 아닙니다.

기존 save 데이터는 보존하려는 호환성 코드를 추가했지만, **기존 월드는 백업하고 새 시험 월드에서 검증하십시오.** 기연 생성은 `config/murimlife-opportunities.json`의 `enabled`를 `false`로 바꾸면 끌 수 있습니다. 기존 문파 거점 월드 생성은 독립 설정으로 기본 OFF인 상태를 유지합니다.

- 일회성 서버측 트랩이 독·둔화·실명·즉시 피해를 가할 수 있습니다.

설정 기본값: `enabled=true`, `sectorChance=0.67`, `minimumDistanceFromSpawn=150`, `maximumSitesPerWorld=1000`.

## 2. NPC 대화와 정보

- MURIM LIFE NPC, 바닐라 주민(Villager), 떠돌이 상인(WanderingTrader)을 바라보며 `~` 키(기본 Grave Accent)에 대화 요청합니다. 기존 우클릭 거래는 이 대상들에 대해 취소합니다. **타사 모드가 추가한 임의의 NPC에는 자동 적용되지 않습니다.**
- ① 기연 소문 ② 지금/다음 문파 모집 ③ 정기 무림대회 지정일 ④ 구파일방·오대세가·무림맹·사도련 위치 ⑤ 상세 기연 정보 ⑥ 상점 열기 ⑦ 소매치기 ⑧ 허위정보 추궁 ⑨ 종료 등의 클릭 가능한 채팅 선택지.
- 주민은 일정 횟수 질문 후 더는 모른다고 말하며, 점소이는 추가 정보에 돈을 요구합니다. 상인은 더 비싸지만 지형과 문파·대회 정보를 더 많이 제공합니다. 단, 고급 기연 정보는 일부 거짓입니다.
- 문파·연맹 본부 좌표는 **기존 거점 생성기가 실제로 시공을 기록한 곳만** 공개합니다. 생성되지 않은 곳은 정직하게 좌표 미확인으로 나타냅니다. 기연 제보도 이미 세계에 생성돼 저장된 기연을 기준으로 합니다.
- 상인은 고급 기연 정보에서 기본 **12% 거짓 정보 확률**(신뢰 하락 시 상승), 점소이는 **26%**입니다. 상인의 허위 정보에 대해 기록된 제보 지점을 찾지 못하면 추궁할 수 있습니다: 환불+배상, 협박(악업), 공개 고발, 용서.
- 현재 정보와 상점 UI는 **클릭 가능한 채팅 메뉴**입니다. 별도 그래픽 상점 창과 NPC 음성/생성형 자연어 대화는 아직 없습니다.

## 3. 화폐와 경제

화폐 단위: **100문 = 1은량, 10은량 = 1금량**, 저장의 원래 `silver` 필드를 은량으로 유지하고 하위 단위 `copper`를 새로 추가합니다. 모든 내부 거래는 문 단위 정수 연산을 사용합니다.

- `/murim money`: 소지금 확인.
- NPC를 처치하면 사망한 대상의 남은 소지금과 전투 보상 상한 중 작은 값을 획득합니다. 기본 소지금은 경지의 제곱과 직업(상인)에 따라 증가합니다. 반복 처치 지급 방지 표식을 두고, 관중/대련 상대는 제외합니다.
- `MurimEvil` 표식이 있거나 일반 습격자인 상대를 처치하면 선업이 증가하고, 무고한 NPC 피해는 악업을 발생시킵니다.
- 소매치기는 NPC 정보 메뉴에서 시작하고 **실제 시간 대신 게임 100틱(약 5초)** 동안 우클릭을 반복합니다. 5회 미만 클릭이면 자동 실패, 초당 10회 상한, 서버 거리·시간·대상 검증, 1인당 1일 1회 대상 제한이 있습니다.
- 성공 확률 = 기본 13% + (민첩/기교/감각 10 초과 보정) + 클릭당 2.4%(최대 30회) - 상대가 더 높은 경지일 때 단계당 13.5%; 최저 4%, 최고 92%. 실패 시 악업 +5, 성공 시 +2. 상대가 강할수록 소지금은 증가합니다.
- 플레이어 문파 창설: `/murim sect found <문파명>` (50은량). 소속원 초대/승인 `/murim sect invite <이름>`, `/murim sect accept`; 가주 승급 `/murim sect promote <이름> <등급>`; 탈퇴 `/murim sect leave`; 문파 금고 `/murim sect treasury balance` 및 `deposit <문>`.
- 창립자가 아닌 문파원의 **3일 주기 용돈**: 외문제자 **75문**, 내문제자 **180문**, 사부 **420문**, 장로 **850문**. 창립 문파에서는 회원 수·직급만큼 총액을 문파 금고에서 지급하며, 잔고 부족 회원은 해당 주기에 미지급됩니다. 정파·세가 기존 소속은 월드 경제 지급의 시범 규칙을 따릅니다.
- 문파 모집은 정보 조회 규칙과 달리 **실제 입문 시험 3단계까지 자동 구현된 것은 아닙니다**. 관리자 테스트 명령 `/murim sect setmember <플레이어> <문파> <등급>`을 제공하며, 플레이어 창설 문파는 초대·수락 방식입니다.

## 4. 상인 거래

- 상인에게 `~` → `[상점 열기]` → 클릭 가능한 구매/판매 항목. 음식·약초·무기·서적·여행·잡화 등 **6개 품목군**이며 NPC 직업에 따라 선택됩니다.
- 상인 개체마다 재고를 저장하고, 월드 시간 **48,000틱(2일)** 단위로 재고를 다시 설정합니다.
- 구매는 서버에서 물품·재고·소지금·거리·상인 종류를 검사한 후 지급됩니다.
- 판매는 **현재 들고 있는 물건 1개만**, 해당 상인이 매입하는 품목이 목록에 있는 경우에만 가능합니다. 모든 아이템을 무조건 팔 수 없습니다.
- 상인이 거짓 정보를 제공한 기록이 있고 허위가 증명되면 신뢰 불량으로 미래 재입고가 줄어드는 사회적 제재가 적용됩니다.

## 5. NPC의 시선과 자연스러운 행동

MURIM LIFE 인간형 NPC의 `LookAtPlayerGoal` 상시 바라보기 목표를 제거했습니다. NPC 고유 이동·순찰/경기 AI는 이전 기능을 유지합니다. **바닐라 주민은 Minecraft 자체의 생활/시선 AI를 따르므로 가끔 플레이어를 볼 수 있습니다.** 기존 월드의 다른 NPC 모드 시선 AI를 변경하지 않습니다.

## 6. 테스트 결과와 한계

`bash scripts/test_v123.sh` 및 `QA_V123_WINDOWS.cmd`는 Java 구문, 중복 선언, 기연 12종 등록, 기존 데이터, 새 화폐/소매치기 계산을 검증합니다. 기초 자원 1,647개(.png/.nbt)는 원본 SHA-256 일치를 확인했습니다. **아직 NeoForge 타입 체커가 확인한 결과가 아니며 게임 실행도 확인되지 않았습니다.**

빌드 시도(인터넷 필요): Windows `BUILD_WINDOWS.cmd`, Linux `./gradlew clean build --stacktrace`. 빌드가 실패하면 `build_log_unified.txt` 또는 Actions의 `build_log.txt`를 전달해야 실제 API 불일치를 정정할 수 있습니다.
